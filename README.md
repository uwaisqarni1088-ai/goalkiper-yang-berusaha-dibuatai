# Goalkeeper: Yang Berusaha Dibuat

3D football goalkeeper game prototype for browser.

## Features
- 3D pitch and players
- 11v11 team formation display
- Player controls: left dive, right dive, analog positioning
- Level selection: Easy, Medium, Hard
- AI shot sequence with goalkeeper save logic
- Pure browser game using Three.js from CDN

## Run locally
1. Open a terminal in this folder.
2. Run:
   ```bash
   python -m http.server 8000
   ```
3. Open:
   ```text
   http://localhost:8000
   ```

## Controls
- Left button: jump to the left
- Right button: jump to the right
- Analog slider: move the goalkeeper left/right to cover the shot angle

## Notes
This is an early prototype focused on playable mechanics rather than full 11v11 strategic simulation.

The project is designed to be easy to modify and expand.
